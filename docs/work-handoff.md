# Work 執行任務｜沼氣巡檢員資產與 20 頁手冊

## 一、第一優先：上傳官方角色參考圖片

已有兩張在 ChatGPT 對話中建立的 PNG，請使用者在 Work 對話中附加 `biogas-mascot-reference-v0.1.zip`（內有兩張原始 PNG）後再執行。

將解壓縮後原始圖片原封不動保存至：
- `assets/mascot/reference/mascot-character-sheet-v0.1.png`
- `assets/mascot/reference/mascot-pose-sheet-v0.1.png`

要求：
1. 上傳至 GitHub `itribioenergy/Biogas-Plant-Guidelines` 的 main 分支；保持 PNG 不變。
2. 讀取角色設定 `docs/mascot-spec-v0.2.md`，將兩張 PNG 定為角色身份依據。角色定稿仍需使用者確認。
3. 後續生成所有姿態時，優先提供原始角色設定圖作為參考圖，不可以只依文字生成；使用固定帽子葉片、胸章、面罩、眼睛、四肢比例及配色。每次輸出都需比對原始角色設定圖。
4. 新圖出現角色漂移（安全帽標誌、臉孔、胸章、顏色、手腳比例不同），拒收並重新生成。
5. 標準姿態圖中「注意警示」表情略輕鬆，應在高風險內頁用更嚴肅版本；不能把圖片上的警告字當成技術指令。
6. PNG 上的文字與色票是視覺參考，不等同正式排版規格；以 `docs/visual-spec-v0.2.md` 為準；若色票與正式規格不一致，更新規格並寫設計決策紀錄。

## 二、第二優先：手冊 v0.1 可討論完整版本

以既有 `docs/outline-v0.1.md` 與原始 109 年農業部委託工研院中分院手冊為基礎，製作 A4 直式封面＋20 頁內文，對象為農民與非環工專業業主。

- 雙主軸：生物系統與發電機，另設沼氣前處理、安全與實用工具。
- 一頁一問題，採「看現象→初步判斷→安全行動→需要專家時」標準頁面。
- 先建可預覽網站，再生成可列印 PDF 與可編輯 Word。
- 每頁以圖片、流程圖、對照圖與簡短文字為主。
- 不得捏造設備標準數值；保持原廠設定與現地正常歷史數據優先。
- 沼氣外洩、H2S、缺氧、電氣與機械異常問題僅呈現安全辨識／通報／撤離及專業處置界線。
- 技術內容涉及原始文獻時保留來源，與模型新增建議明確區分。

## 三、工程品質與版本管理
- 將角色 PNG 視為 immutable reference master，不覆寫；新圖另存版本。
- 網站內文以獨立資料檔管理，不將 20 頁全部硬寫進單一 UI 檔案。
- 每次完成一批產出執行 build、檢查圖片載入、A4 列印斷頁與文字溢出。
- 提交 GitHub commit，並更新 `docs/design-decisions.md`。
- 用戶明天早上要在會議展示，優先提交可運行的「封面＋20 頁可翻閱初版」，不把未經審查內容標為正式操作標準。
- 若工作有權限或執行額度限制，優先留下能運作的初稿和清楚的待辦，不可假稱全部完成。
