# 沼氣場健康檢查手冊｜企劃架構 v0.1

> 狀態：內容與章節提案，待討論確認。此版不是正式操作程序或最終設計。

## 專案定位
- 對象：農民、牧場負責人與非環工背景之案場業主。
- 目標：讓使用者透過「觀察 → 初判 → 安全處置 → 尋求協助」快速了解案場狀態。
- 預計格式：A4 直式，封面不計約 20 頁；以圖文為主，少公式、少艱澀用語。
- 章節：生物系統／沼氣處理與安全／發電機系統／實用工具。
- 原始參考：工研院中分院《沼氣再利用（發電）推廣與沼氣發電機操作手冊》（109 年 7 月，111 PDF 頁）。

## 編輯原則
1. 先從症狀與現場觀察切入，再補必要原理。
2. 每頁固定包含「怎麼看、可能原因、可安全採取的行動、何時找專業人員」。
3. 不提供不具通用性的絕對數值；各機型與案場須以原廠規格、設計基準與歷史正常值確認。
4. 用綠／黃／紅三級標示，但紅燈涉及燃氣洩漏、硫化氫、機械超速與電氣危害時，強調撤離、隔離及由受訓人員處置，不鼓勵讀者自行維修。
5. 吉祥物提案：沼氣寶（暫名），定位為巡檢解說員而不是裝飾。
6. 圖片需標示來源、授權及適用機型；圖片、診斷門檻需經技術審查。
7. 舊手冊之 109 年補助、設備價格、費率與保養建議等，不直接當成現行標準。

## 單頁版式範例（脫硫設備）
- 標題：脫硫設備有在工作嗎？
- 看現象：發電機進氣端 H₂S 量測結果、耗材使用情況、壓差與異常警報。
- 初判：可能是脫硫材已接近飽和、流量改變、旁通或操作條件異常。
- 安全行動：記錄儀表讀值、對照原廠／案場設定，通報受訓人員依程序處理。
- 紅燈：疑似洩漏或 H₂S 警報時勿靠嗅聞辨識，遠離危險區並依緊急程序通報。
- 插圖：脫硫塔與「前後端量測點」示意、三色燈號。

## 需要審查的技術內容
- pH、溫度、VFA／鹼度、日產氣量、甲烷與 H₂S 警戒值：應區分示意值與場域特定值。
- 發電機冷卻液、機油、啟動／停機步驟與保養週期依設備原廠。
- 氣袋、氣體管線、H₂S、甲烷、缺氧、爆炸、電力系統之安全事項須專業審查。
- 不將過時的行政機關名稱、補助、費率、聯絡窗口與價格直接沿用。
