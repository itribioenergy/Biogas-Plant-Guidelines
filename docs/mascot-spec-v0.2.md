# 沼氣巡檢員｜角色設定 v0.2

**代稱：** 沼氣巡檢員 / Biogas Inspector Buddy（正式命名待決）
**角色定位：** 幫助非專業讀者辨識設備、理解警訊、查找頁碼的安全導覽助手。
**個性：** 活潑、好奇、有一點俏皮，但面對安全問題嚴肅可靠。不說教、不搞笑帶過風險。

## 1. 角色設計不變元素（Character DNA）
1. **輪廓：** 圓潤工程巡檢機器人，2.5–3 頭身；稍大頭、短而活動自如的四肢，站姿重心穩。
2. **頭盔：** 黃色安全帽（固定外觀特徵），中央一枚簡約綠色葉片或能源符號，帽沿與臉部不可互相遮擋。
3. **臉：** 深色面罩或純色臉部區，兩顆具表情的數位眼睛；嘴部為少量曲線，可做驚訝、專心、微笑與嚴肅。
4. **機身：** 主體品牌綠 `#4FA36C`，局部深綠 `#2F6B45`、奶白與少量科技藍；胸前固定「葉片+小儀表」合成徽章，勿每張隨意更換。
5. **手與腳：** 每手 3 指的簡化手套、圓角工作靴；比例統一；不畫過多機械零件。
6. **畫法：** 2D 平面向量插畫、乾淨中等粗細外框、極少量陰影；避免 3D 寫實、毛茸茸玩偶風、重金屬戰鬥機器人風。
7. **角色比例：** 正面設定圖全身高 100 單位：安全帽與頭佔約 38、軀幹約 34、腿腳約 28（非強制幾何量尺，作為畫師比例參考）。
8. **辨識重點：** 頭盔+綠色身體+胸章+眼睛，一張圖再小也能看出是同一個角色。

## 2. 色彩及零件
| 部位 | 規格 |
|---|---|
| 頭盔 | 黃色 `#F0C84B`；深金色少量陰影 |
| 主要機殼 | `#4FA36C` |
| 關節與描邊 | `#2F6B45` |
| 面罩 | 深灰綠 `#303A36` |
| 眼睛 | 白色或清亮科技藍 `#5D89C7` |
| 胸部徽章 | 白底、綠葉＋小儀表指針，圖形固定 |
| 警示道具 | 與狀態語意一致，不可改變角色本體主色 |

## 3. 標準姿態與表情（首批必備）
| 資產 ID | 姿態 | 表情 | 用途／搭配台詞 |
|---|---|---|---|
| `mascot-guide` | 手持地圖、開掌導覽 | 明亮微笑 | P01/P03：「先找到你想檢查的單元！」 |
| `mascot-inspect` | 放大鏡靠近設備外側 | 專注好奇 | 各單元觀察頁：「先看儀表與外觀。」 |
| `mascot-ok` | 比 OK、另一手持夾板 | 放鬆微笑 | 正常對照；避免用於未確認安全的場景 |
| `mascot-think` | 一手托腮、旁有問號 | 疑惑專注 | 多原因診斷頁：「先比對最近有什麼變化。」 |
| `mascot-watch` | 舉黃色注意標誌 | 謹慎、眉毛收緊 | 警戒趨勢：「記下異常，儘快確認。」 |
| `mascot-stop` | 正面伸手制止、紅色 STOP 牌 | 嚴肅，不微笑 | 高危風險：「先離開危險區並通報。」 |
| `mascot-record` | 手持平板與觸控筆 | 專心 | 巡檢表、運轉紀錄 |
| `mascot-call` | 手持通訊器、指向求援資料 | 安定、認真 | P20：「把警報和時間一起提供給技師。」 |

每個動作需同時輸出全身版與裁切半身版（並保有相同角色辨識）。

## 4. 表情字典
- 開心：微彎眼、輕笑；僅一般導讀與正常說明
- 好奇：一邊眉毛上揚、眼神聚焦；用於搜尋原因
- 謹慎：眉毛略壓、嘴平直；用於黃色注意
- 嚴肅：眉毛收緊、嘴緊閉；用於紅色危險
- 鼓勵：溫和微笑、張開手掌；用於完成記錄和後續追蹤

**禁止**在危險、漏氣、疑似硫化氫暴露等情境使用大笑、眨眼賣萌或滑稽動作。

## 5. 道具規格
必備：檢查板、平板、放大鏡、手電筒、黃／紅警示牌、通訊器、簡化地圖。
扳手只可作為「有維修專員」的一般象徵，**不得**畫成鼓勵農民自行拆卸燃氣管線、電盤或高風險設備。

## 6. 姿態對應頁面
- P01：guide；P02：record；P03：guide
- P04：inspect；P05：inspect；P06：think；P07：inspect；P08：watch
- P09：inspect；P10：watch；P11：inspect；P12：stop
- P13：record；P14：think；P15：watch；P16：record；P17：ok（保養完成情境）
- P18：guide；P19：record；P20：call

## 7. 使用限制
- 正式內容一頁最多 1 個主角色，避免分散注意。
- 危險警示必須先出現明確文字與圖示，吉祥物只能輔助。
- 同一角色不可變色扮演不同章節，改用配件或頁首色區分。
- 禁止出現無安全帽、外觀突然改成動物、成人身材、實寫金屬人或不同胸章。
- 禁止在精確設備結構圖上以角色遮住重要閥件、箭頭或量測點。
- 圖示旁的字必須在手機與列印尺寸上可讀；角色本身不承載關鍵數值。

## 10. 驗收條件
- 八個姿態並排，安全帽、胸章、臉、四肢比例一致。
- 放到約 25 mm 高印刷仍可辨識。
- 表情含義明確，不靠顏色作唯一區別。
- SVG 檔具獨立可編輯元件，PNG 具有透明背景。
- 資產由可合法使用、可再次編修的來源產生。
