# 沼氣場健康檢查手冊（企劃中）

**Biogas Plant Guidelines** ｜工研院綠能所沼氣案場輔導手冊規劃

目標是提供農民及非環工背景業主一份約 20 頁、以圖文為主、可以快速查找異常狀況的沼氣案場巡檢工具。

目前是 **v0.1 章節企劃階段**，尚未完成技術審查或可直接採用的現場操作規程。

- [查看 20 頁章節規劃](docs/outline-v0.1.md)
- 雙主軸：**生物系統**與**發電機系統**，包含沼氣處理及安全章節
- 核心閱讀路徑：**看現象 → 判斷 → 安全處置 → 尋求協助**
- 預計功能：網頁預覽、版次管理、PDF 與 Word 匯出
- 吉祥物暫名：「沼氣寶」

> 注意：發現沼氣洩漏、硫化氫警報、設備異常超速或電氣危害時，應按案場安全程序撤離與通報，勿依示意自行拆修設備。
